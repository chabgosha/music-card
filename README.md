# Музыкальная открытка

Веб-сервис для кейса №6 хакатона «Время IT»: человек пишет поздравление, записывает
его своим голосом, выбирает музыку и громкость, слушает результат и получает ссылку.
Получатель открывает ссылку, видит конверт, нажимает «Открыть» — и слышит голос под музыку.

---

## Быстрый старт (Windows)

1. Нужен Python 3.10 или новее (у вас уже стоит 3.13). Если ставите заново — на python.org,
   с галочкой **Add python.exe to PATH**.
2. Распакуйте архив в любую папку.
3. Дважды щёлкните **`run.bat`**. В первый раз он создаст папку `.venv` и поставит библиотеки (около минуты).
4. Откройте в браузере **http://localhost:5000** — это конструктор.
5. Адрес для телефона напечатан в консоли: строка «С телефона (та же сеть)», например `http://192.168.0.5:5000`.

Если Windows спросит про брандмауэр — нажмите **«Разрешить доступ»** (для частных сетей).

### Запуск вручную

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py                   # или: python app.py --port 8080
```

ffmpeg отдельно ставить не нужно: он приходит вместе с пакетом `imageio-ffmpeg`.

## Сценарий для показа жюри (2–3 минуты)

1. Ноутбук: открыть `http://localhost:5000`.
2. Повод «День рождения» — открытка справа меняет цвет, марку и подбирает бодрую музыку.
3. Вписать «Кому», текст и «От кого» — текст сразу появляется на открытке рукописным шрифтом.
4. Отметить согласие → нажать красную кнопку → сказать поздравление → нажать ещё раз.
5. В «Музыке» нажать «Создать свою мелодию» → выбрать настроение → «Ещё вариант».
   Мелодия сочиняется прямо сейчас и заканчивается финальным аккордом точно после голоса.
6. Двинуть ползунок музыки → «Прослушать открытку».
7. «Создать открытку» → появятся ссылка и QR-код.
8. Телефон в той же сети сканирует QR → конверт → «Открыть открытку» → звучит.

**Страховка:** заранее создайте 1–2 открытки и держите их ссылки открытыми на телефоне,
а также запишите видео этого сценария. Если сеть на площадке подведёт — показываете видео.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Телефон не открывает ссылку | 1) Телефон и ноутбук в одной сети? 2) Профиль сети Windows — **«Частная»** (Параметры → Сеть → свойства Wi-Fi). 3) Разрешите Python в брандмауэре. 4) В общественном Wi-Fi устройства часто изолированы друг от друга — включите раздачу с телефона или свой роутер. |
| В консоли адрес `127.0.0.1` | Ноутбук не подключён ни к какой сети. Подключитесь и перезапустите. |
| Включён VPN | Программа сама выбирает адрес Wi-Fi, а VPN-адреса (например `10.8.x.x`) показывает отдельно. Но некоторые VPN не пускают телефон к ноутбуку, поэтому на время показа VPN лучше выключить и перезапустить `run.bat`. |
| Выбран не тот адрес | В консоли есть список «Другие адреса компьютера». Перезапустите с нужным: `run.bat --ip 192.168.0.5`. Свой адрес Wi-Fi можно посмотреть командой `ipconfig`. |
| На телефоне нет кнопки записи | Браузер разрешает микрофон только на `localhost` или по `https`. Запустите `run_https.bat` вместо `run.bat`: ссылки и QR станут `https://…`. На телефоне при первом заходе нажмите «Дополнительно» → «Перейти на сайт» (iPhone: «Подробнее» → «посетить этот веб-сайт»), дальше запись работает. Сертификат лежит в `certs/` и не меняется между запусками. |
| «Address already in use» | Порт занят — скорее всего, сервер уже запущен в другом окне. Закройте его или запустите `python app.py --port 5001`. |
| Браузер не дал микрофон | Значок замка/камеры слева от адреса → разрешить микрофон → нажать запись снова. |

## Как устроено

```
Браузер (конструктор)                Сервер Flask (app.py)                Хранение
───────────────────                  ─────────────────────                ────────
запись голоса (MediaRecorder) ─POST /api/uploads──► mixer.prepare_voice ──► data/uploads/voice-*.wav
выбор/загрузка музыки ─────────POST /api/uploads──► проверка файла ───────► data/uploads/music-*
ползунки → «Прослушать» ───────POST /api/preview──► mixer.build_card ─────► data/previews/*.mp3
«Создать открытку» ────────────POST /api/cards────► mixer.build_card ─────► data/cards/*.mp3
                                                    storage.add_card ─────► data/cards.db (SQLite)
Браузер (получатель) ──────────GET /c/<код>────────► страница с конвертом
                               GET /c/<код>/audio──► итоговый mp3
```

| Файл | Что делает |
|---|---|
| `app.py` | Веб-сервер: страницы, API, QR-код, отложенное открытие |
| `network.py` | Выбор адреса компьютера в Wi-Fi для ссылок (VPN и виртуальные адаптеры — в конец списка) |
| `mixer.py` | Сведение звука (развитие функции `build_card` из первой версии) |
| `composer.py` | «Своя мелодия»: сочиняет музыку по настроению под длину голоса |
| `photos.py` | Фото на открытке, ответ-селфи получателя, страница статуса `/s/<token>` (подробно в `PHOTOS.md`) |
| `storage.py` | База SQLite: таблицы `uploads` (голоса и музыка) и `cards` (открытки) |
| `templates/` | HTML: `index.html` — конструктор, `card.html` — получатель, `_postcard.html` — сама открытка |
| `static/js/create.js` | Логика конструктора: запись, загрузка, предпросмотр, создание |
| `static/js/card.js` | Конверт, анимация открытия, обратный отсчёт |

| `music/` | Подборка треков, `tracks.json` — список, `LICENSES.md` — права |
| `tools/make_music.py` | Генератор фоновой музыки (numpy) |
| `legacy/music_card_console.py` | Первая, консольная версия проекта — для истории |

### Как сводится звук (`mixer.py`)

1. Голос: ffmpeg декодирует любой формат (webm из Chrome, m4a с iPhone, mp3, wav),
   убирает низкий гул (фильтр 80 Гц), обрезает тишину по краям, выравнивает громкость до −18 dBFS.
2. Музыка: тоже выравнивается до −18 dBFS, чтобы ползунки работали одинаково для любого трека.
3. Ползунок 0–100 % переводится в децибелы: `20·log10(p/100)`.
4. Раскладка: 2 с музыки → голос → 3 с музыки с затуханием. Пока звучит голос,
   музыка автоматически тише на 7 дБ (приём «ducking», как на радио).
5. Пик ограничивается −1 dBFS, чтобы не было хрипа. Результат — один mp3.

### Как сочиняется своя мелодия (`composer.py`)

1. **Настроение задаёт правила.** Весёлая — мажор, 120–132 уд/мин, щипковые аккорды и ударные;
   нежная — минор, 64–72, пианино-арпеджио без ударных; праздничная — «фанфары», колокольчики,
   бочка на каждую долю; сказочная — лидийский лад (мажор с «волшебной» IV ступенью) и
   музыкальная шкатулка; романтичная — вальс на 3/4, пианино и струнные, септаккорды.
2. **Случайное число (seed) выбирает всё остальное:** тональность, темп внутри диапазона,
   две последовательности аккордов, ритм и рисунок мелодии. «Ещё вариант» = новый seed.
3. **Мелодия по правилам, а не случайные ноты:** фраза «мотив A — ответ B», на сильных долях —
   только звуки текущего аккорда, остальные идут шагами по ладу.
4. **Под длину голоса:** число тактов считается так, чтобы после голоса прозвучала каденция
   V → I и финальный аккорд. Поэтому музыка не зацикливается и не обрывается затуханием.
5. **Мотив из имени** (галочка): буквы имени получателя превращаются в ступени лада (а=1, б=2, …).
6. Одинаковые настроение, seed и имя всегда дают одну и ту же мелодию: в открытке хранится только
   `gen:<настроение>:<seed>`, а mp3 кэшируются в `data/melodies/`. Сочинение занимает 1–2 секунды
   и работает без интернета.

### Решения с точки зрения пользователя (пригодится для вопросов жюри)

- **Один mp3 на сервере, а не два звука в браузере.** Получатель на любом телефоне слышит
  ровно то, что прослушал отправитель; файл можно скачать и переслать.
- **Без регистрации.** Открытку делают за пару минут, а получатель открывает её
  без аккаунта. Ссылка содержит случайный код — перебрать чужие открытки нельзя.
- **Конверт перед открыткой.** Браузеры не включают звук без нажатия. Конверт превращает
  это ограничение в момент сюрприза: нажал «Открыть» — и сразу зазвучало.
- **Согласие на запись голоса** — по правилам хакатона (п. 4.4); без галочки запись не начнётся.
- **Своя мелодия — в один клик.** Подбирать трек по каталогу долго; проще выбрать настроение
  и послушать. Настроение по умолчанию берётся из повода (день рождения → весёлая, Новый год →
  сказочная, спасибо → нежная, поздравляю → праздничная, с любовью → романтичная).
- **Своя музыка — только с подтверждением прав.** Встроенные треки созданы скриптом проекта,
  поэтому вопросов о правах нет.
- **Текст до 300 символов.** Больше не помещается на открытку; длинное поздравление лучше сказать голосом.
  Чем длиннее текст, тем мельче почерк — он всегда помещается.
- **Отложенное открытие** (доп. функция кейса): до назначенного времени получатель видит конверт
  с обратным отсчётом, а сервер не отдаёт звук.
- **Работает без интернета** — нужен только Wi-Fi или раздача, в которой есть ноутбук и телефон.

### API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/tracks` | Список треков подборки |
| POST | `/api/uploads` | Загрузить голос (`kind=voice`, `consent=1`) или музыку (`kind=music`, `rights=1`) |
| GET | `/api/moods` | Настроения для своей мелодии |
| POST | `/api/melody` | `{mood, seed?, name?}` → `{id: "gen:…", url, title}` — сочинить мелодию |
| POST | `/api/preview` | `{voice_id, track, voice_volume, music_volume}` → ссылка на предпросмотр |
| POST | `/api/cards` | Всё выше + `theme, recipient, sender, message, open_at` → `{code, url, qr_url}` |
| GET | `/c/<code>` | Страница получателя |
| GET | `/c/<code>/audio` | Звук открытки (`?download=1` — скачать) |
| GET | `/c/<code>/qr.svg` | QR-код ссылки |

## Что можно доделать

- Свои цвета и тексты поводов — словарь `THEMES` в начале `app.py`.
- Больше треков: см. `music/LICENSES.md`.
- Обрезка записи, визуализация звуковой волны, список созданных открыток.

## Музыка и сторонние компоненты

- Музыка в `music/` — синтезирована скриптом `tools/make_music.py`, принадлежит команде.
  Своя мелодия синтезируется `composer.py` теми же инструментами — тоже без чужих сэмплов.
- Шрифты Onest и Caveat — лицензия SIL Open Font License (файлы лицензий в `static/fonts/`).
- Библиотеки: Flask (BSD), pydub (MIT), qrcode (BSD), imageio-ffmpeg (BSD-2), ffmpeg (LGPL/GPL), numpy (BSD).
- Веб-часть написана с помощью ИИ-ассистента Claude и проверена командой.
